# Python 代码审查 Skill

## 工作流程

1. 阅读用户提供的 Python 代码。
2. 检查语法错误。
3. 检查逻辑错误。
4. 检查潜在的安全问题。
5. 提供修改建议。

## 规则

- 默认使用中文回答。
- 不要未经允许修改代码。
- 解释每个发现的问题。
- 给出具体的修复方案。


## 自动语法检查

当用户要求检查 Python 文件时：

1. 确认目标 Python 文件的路径。
2. 定位本 Skill 目录中的 scripts/check_syntax.py。
3. 使用 Python 执行该脚本，并传入待检查文件路径。
4. 阅读脚本返回的 PASS 或 FAIL。
5. 解释检查结果，并提供必要的修复建议。

## 注意事项

- 检查前先确认文件已经保存。
- 使用 Skill 自身的实际安装路径定位脚本。
- 不要直接执行被检查的 Python 文件。
- 未经用户允许，不得修改源代码。



## GitHub MCP 代码审查

当用户要求检查 GitHub 仓库时：

1. 确认目标仓库的 owner 和 repository 名称。
2. 检查当前 Agent 是否具有 GitHub MCP 工具。
3. 使用 GitHub MCP 读取仓库目录和目标源代码。
4. 优先检查 Python 文件。
5. 如果需要自动语法检查，将代码保存到授权的临时工作目录，再运行 scripts/check_syntax.py。
6. 分析逻辑错误、安全风险和代码质量。
7. 输出中文代码审查报告。

## GitHub 操作规则

- 默认只读取仓库内容。
- 不创建提交或 Pull Request。
- 不修改 GitHub 仓库中的任何文件。
- 不执行仓库中来源不明的代码。
- 如果缺少访问权限，明确报告，不得虚构检查结果。
- 未运行的检查不得声称已经通过。
